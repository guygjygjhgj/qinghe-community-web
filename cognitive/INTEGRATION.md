# 认知小游戏接入记录

来源：用户提供的 `青禾社区_认知测评交互演示_交付包.zip` 中 `dist/`。
保留原题目、计时、报告、样式和图片；仅替换占位社区返回函数，增加同源消息桥与返回首页按钮。

首次登录进入首页时，由主应用加载本目录的独立页面。完成或稍后体验的标记按账号保存在当前浏览器的社区状态中，不同步到审核服务。原有返回活动、发帖等登录目标仍先正常返回，第一次进入首页再展示。

主应用只接收 `finished` / `deferred` 的流程状态，不接收逐题答案。任务记录仍只在小游戏内存中，可由用户主动导出，刷新或离开后清空。保留课程演示标识和无临床分级的原有说明。

演示默认只显示应用屏幕，隐藏屏外说明、讲解面板和缩放工具栏；屏幕内保留说明、大字、暂停、跳过和返回操作。屏外调试工具只在显式 `demoTools=1` 参数下启用。
