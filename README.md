# 青禾社区

居民端网页，包含首页、植物圈、社区活动、消息、种苗约定、个人植物记录、收藏、草稿、发布与设置。

界面使用 Figma 中的原始图片、花体字图片、图标和文字图层，保留各画板自己的宽高、图片裁切、文字框和控件位置。画板宽度包括 698、750、848、850、851、852 像素；窗口较小时通过滚动查看，不压缩图片。

## 运行

使用 Node.js 20 或更新版本：

```sh
npm start
```

打开 `http://127.0.0.1:4180/`。可以直接部署目录内的静态文件到 GitHub Pages。

```sh
npm test
npm run check
```

## 交互与数据

支持填写和发布、保存草稿、删除草稿、添加植物、记录成长、收藏、留言、种苗申请与交接、活动报名及取消、筛选和设置。文本和按钮使用独立 DOM 控件；装饰图片沿用原素材。

当前数据保存在浏览器本地。短信、跨用户消息、社区工作人员接收反馈以及远端账号服务尚未连接；此仓库不代表这些服务已上线。语音功能取决于浏览器和设备支持。

## 设计结构

- `native/`：57 张 Figma 画板对应的独立页面模块。
- `native-layers.css`：从设计图层转换的原生 CSS。
- `native-geometry.js`、`layer-manifest.json`：原图层的坐标、宽高、字体、字距和图片边界。
- `native-views.js`：页面选择及原控件的交互绑定。
- `app.js`：路由、表单、弹窗和操作流程。
- `domain.js`：植物、帖子、草稿、种苗、报名等数据规则。
- `assets/`：下载并保留的原始素材；页面不请求临时 Figma 素材地址。

独立画板可通过 `#/design/home`、`#/design/profile` 等路径查看，主要交互入口是 `#/`。

字体的许可信息位于 `assets/fonts/LICENSE.txt`。界面图片与设计的权利属于各自权利人。
