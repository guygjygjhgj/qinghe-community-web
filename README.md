# 青禾社区 · Figma 原稿交互版

设计来源：[青禾社区 App｜可编辑 UI 总集](https://www.figma.com/design/ogLazRKEe0qapAgKaqnWBJ?node-id=0-1)。

## 当前界面规则

全部 58 张画板直接使用 Figma 导出的原始图层。操作页面也使用这些图层，不再使用 flow / experience 重新排版的卡片、统计行、轮播按钮或底栏。

- 原画板宽高、图层坐标、图片槽位、裁切、比例、字体、颜色和静态文案按源稿保留。
- 750、848、850、851、852 等原画板尺寸分别保留。电脑端默认使用 390 × 780 像素固定演示窗口，按画板宽度等比缩放，长内容在窗口内滚动；可用空间不足时窗口自动缩小。顶部可切换“固定窗口／完整页面／原始尺寸”，也可使用 ＋／− 调整演示宽度；保留输入与当前阅读位置，不重排图层。窄屏触屏移动端保留原显示方式。
- 可更换的视觉内容只有分享帖子图片、本人头像与昵称。新图片仍放入原有图片槽，不增加卡片或改变槽位尺寸；其他静态图片与文案保留。
- 用户的输入、登录与业务状态通过原控件操作；未提供设计稿的弹窗不新增布局。
- 个人页默认展示原稿“我的植物”画板；空状态可通过 `#/me?empty=1` 查看。

## 本地启动

Windows 双击“启动网站.cmd”，打开 [本地网站](http://127.0.0.1:4180/#/me)。双击“停止网站.cmd”可停止服务。

也可运行：

```sh
npm start
```

原稿画板入口为 `#/design/home`、`#/design/plants`、`#/design/post` 等。所有名称和原始尺寸列于 `design-source.json`。

## 功能与实现

`native-activities.js` 统一活动筛选、活动卡片及报名状态的原稿节点绑定。`native-views.js` 选择原稿状态画板；`strict-bindings.js` 只把路线、按钮动作与输入框绑定到原始 DOM，不复制重排后的界面。

已修复输入与回显、登录返回、搜索实际对象、发布及 9 张分享图、草稿／收藏管理、聊天历史翻动、种苗约定及交接、活动报名与筛选、植物近况、资料、提醒、语音与帮助入口。所有结果使用原稿控件和卡片。逐页清单及限制见 [INTERACTIONS.md](INTERACTIONS.md)，控件节点与动作见 `interaction-audit.json`。

首页“小乐趣”卡片进入菊花，原“轻松体验”位置选择桂花、丝瓜、玉米、银杏、棉花。游戏使用已有代码和素材，以独立 iframe 和存储键隔离；首页“当季推荐”进入新增的游戏／好友游戏圈（#/seasonal），五个横向入口分别进入桂花、棉花、丝瓜、玉米、银杏；首页“小乐趣”仍单独进入菊花。

注册申请、审批及登录会话已接入共享演示服务，注册必须由所有者核对验证码并手动批准；不发送真实短信。登录原稿保持不变，首次提交为注册，审批通过后可再次获取验证码登录。审核入口与部署说明见 `DEPLOYMENT.md`。帖子、聊天等业务数据仍保存在当前浏览器，邻居设备同步与工作人员反馈接收尚未接入。语音识别依赖浏览器、权限与设备服务，未进行真实麦克风实录验证；已测试权限延迟、取消、结束与确认时的资源释放。固定图片入口说明原稿限制，分享图片和本人头像仍可正常更换。
